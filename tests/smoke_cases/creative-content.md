# Smoke Case: Creative Content

某护肤品牌内容团队提出一组短视频脚本，用夸张情节表现年轻人在熬夜后临时补救的尴尬。脚本有人物和段子，但品牌只在结尾露出，产品作用和人群痛点之间的关系不清楚。

Expected route: `创意/内容`

Expected applicable dimensions:

- `洞察锐度`
- `创意记忆`
- `品牌关联`
- `逻辑通顺`

Expected not applicable:

- `传播势能`: `本方案不评`
- `增长有效`: `本方案不评`

Expected primary opportunity: `品牌关联`
