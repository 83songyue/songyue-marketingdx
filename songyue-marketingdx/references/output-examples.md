## Example 1: Strategy / Brand

Input summary: A home appliance brand wants to move from `耐用可靠` to `日常舒适伙伴`. The proposal lists trends, competitors, and broad proposition lines. No Brief is supplied.

```markdown
## 核心判断

这不是“定位句还不够漂亮”，而是新定位还没有被推出。`日常舒适伙伴`可以是结果，但当前方案没有说清：原来的“耐用可靠”在哪个具体生活时刻失效了，谁因此感到麻烦，以及品牌凭什么从耐用走到舒适。现在换成多数家电品牌也成立。

## 为什么这样判断

方案类型：策略/品牌

本轮适用维度判断：
- 洞察锐度：4。材料只有消费趋势和“用户追求舒适”，没有一个可辨认的家庭角色、触发时刻和相互拉扯的需求；因此不高于 6。
- 品牌关联：4。`耐用可靠`是已有资产，但方案没有把产品、服务或用户关系转成“舒适”的具体资格，新主张仍可替换。
- 逻辑通顺：4。趋势、竞品和新口号都出现了，但缺少“旧资产为什么不足 -> 新矛盾是什么 -> 为什么是这个角色”的中间桥。
- 增长有效：6。方向可以影响长期品牌选择，但尚未说明它会怎样指导产品沟通、服务体验或用户关系。

不评维度：创意记忆，本方案不评；传播势能，本方案不评。

证据边界：未提供 Brief，以下判断只基于方案文本；不推定品牌的产品能力、价格或服务承诺。

当前最该加分：洞察锐度。没有具体的“舒服为何稀缺”，后面的角色和表达只能停在形容词。

## 更锋利的一版

不要把定位写成“给每个家庭更多舒适”，而是先把问题收成一个能决定选择的时刻：当家庭设备本该替人分担琐事，却反过来制造等待、噪音、反复确认和协调成本时，人买的不是一台耐用品，而是一段不必被设备打断的日常。由此把品牌角色定义为“把家务里的不确定，变成可放心交出去的日常秩序”。这比“舒适伙伴”更成立，因为它保留了品牌原有的可靠资产，又给可靠一个新的生活含义。PPT 的策略页可直接写：`耐用解决一次购买的安心；日常秩序解决每天生活的安心。` 后续产品、门店和内容不必都讲“温暖”，而要围绕一个具体问题展示品牌如何少让用户操一次心。若品牌没有相应的服务或产品支点，这句话只能先作为方向，需客户确认后再落成承诺。

## 下一步怎么改

1. 用一个家庭角色、一个高频触发时刻和一组具体麻烦重写洞察页，删去不能推出选择的趋势描述。
2. 把现有产品、服务或渠道资产逐条对应到“少操一次心”，只保留能证明这个新角色的支点。
```

## Example 2: Communications / PR

Input summary: A B2B software launch contains a press release, founder interview, analyst briefing, and customer quote posters. Its central claim is `重新定义团队协作效率`, but it has no news hook or proof.

```markdown
## 核心判断

这份方案缺的不是再加几家媒体，而是一个值得公共讨论的矛盾。现在的“重新定义效率”像发布会标题，不能让行业媒体判断为什么此刻要报道，也不能让用户复述这次更新到底改变了什么。

## 为什么这样判断

方案类型：传播/公关

本轮适用维度判断：
- 洞察锐度：4。材料指向“协作效率”，但没有具体团队在哪个协作时刻被什么摩擦拖慢，属于泛问题。
- 创意记忆：4。`重新定义团队协作效率`是常见主张，缺少能被带走的矛盾、事件名或表达锚点。
- 传播势能：4。新闻稿、专访、媒体沟通和海报都是资源清单；当前没有报道理由、公共动作或可引用的证明，故不高于 4。
- 逻辑通顺：4。产品更新直接跳到宏大判断，没有从用户摩擦推出发布议题。

不评维度：品牌关联，本方案不评；增长有效，本方案不评。

证据边界：未提供 Brief，以下判断只基于方案文本；不推定客户数据、媒体背书或产品功能。

当前最该加分：传播势能。没有一件能被讲清的公共表达，后面的采访和海报只是在放大一句空话。

## 更锋利的一版

把发布从“我们重新定义效率”改成一次对协作碎片化的公开回应。先将方案锁定在一个可验证矛盾：团队并不总是缺工具，而是被反复切换、确认和补信息切碎了工作。发布主题可以写成 `少一次追问，团队就多一段完整工作时间`，但不要直接把它当数据承诺。核心动作不是多发一篇新闻稿，而是把一个真实、经客户授权的协作流程拆成“更新前需要几次补问、更新后哪一步被合并”的公开演示；若没有可公开客户，则改为产品内可复现的任务流程。媒体角度随之变成“企业协作为什么越装工具越忙”，创始人访谈回答这个矛盾，分析师沟通提供观察框架，海报只截取流程中最反直觉的一步。这样每个动作都在证明同一件事，而不是各自替发布会站台。

## 下一步怎么改

1. 从现有功能中选一个最能说明“少一次追问”的具体流程，确认能否公开演示或需要匿名处理。
2. 以该流程重写新闻标题、访谈提纲和海报文案，删掉所有无法被证明的“重新定义”。
```

## Example 3: Creative / Content

Input summary: A skincare brand has short-video scripts about young people improvising after staying up late. The stories are amusing, but the brand appears only in the final frame and the product role is unclear.

```markdown
## 核心判断

这组内容不是不够好笑，而是笑点和品牌没有发生关系。观众能记住熬夜后的狼狈，却不知道为什么这个品牌必须出现在这个故事里；删掉尾板，段子仍然成立。

## 为什么这样判断

方案类型：创意/内容

本轮适用维度判断：
- 洞察锐度：6。`熬夜后临时补救`是可识别场景，但当前只写尴尬，没有进一步找到用户在“想立刻恢复状态”和“没有时间认真处理”之间的冲突。
- 创意记忆：6。夸张段子具备观看性，但没有统一的重复表达、动作或符号，难以让系列被一句话复述。
- 品牌关联：4。品牌只在结尾露出，产品如何解决哪一步临时补救没有被写进戏里，故不高于 4。
- 逻辑通顺：4。熬夜场景能通向护肤需求，但从尴尬桥段到品牌作用的推导断开。

不评维度：传播势能，本方案不评；增长有效，本方案不评。

证据边界：未提供 Brief，以下判断只基于方案文本；不推定产品功效或用户数据。

当前最该加分：品牌关联。先让产品在狼狈发生的那一刻有角色，系列创意才有归属。

## 更锋利的一版

不要把产品留在“尴尬结束后的补救”，而让它成为用户在来不及恢复状态时的一次主动选择。系列可统一为 `今天先别被昨晚定义`：每条片从一个“昨晚留下的证据”开始，例如会议前发现镜子里的自己、临时被叫去拍照、午休收到突如其来的见面通知；主角不是假装完美，而是在有限时间里把自己从昨夜拉回当下。关键画面固定为“删不掉昨晚，但可以先把今天拿回来”的镜前动作，产品在这个动作中承担明确但不夸张的角色。片尾文案可以是：`熬夜不能撤回，今天可以重启。` 若产品并不适合快速使用或不能支持这类表达，应先按真实卖点重写这个动作。这样段子不只是展示狼狈，而是在讲品牌为什么理解并参与用户的临场自救。

## 下一步怎么改

1. 给每支脚本补一段“昨晚证据 -> 临时场合 -> 品牌参与动作 -> 今天重新接上”的同构叙事。
2. 统一一个能反复出现的镜前动作和片尾句，删除仅为搞笑却不能带出产品角色的桥段。
```

## Example 4: Integrated Marketing

Input summary: A local tea-drink brand plans trial tastings, short-video challenge, mall pop-up, delivery coupons, and community giveaways for a summer launch. Its goal is only `让年轻人觉得新品很清爽`.

```markdown
## 核心判断

这是一张执行清单，不是一条整合营销主线。试饮、挑战、快闪、券和抽奖都能做，但它没有回答新品到底要解决尝鲜、复购、到店还是外卖的哪个问题，所以每个动作都只能各自热闹。

## 为什么这样判断

方案类型：整合营销

本轮适用维度判断：
- 洞察锐度：4。`年轻人想喝清爽`只是品类常识，没有具体的夏日触发时刻和选择冲突。
- 创意记忆：4。当前没有统一主题、动作或符号，只有渠道动作。
- 品牌关联：4。没有说明新品或品牌在“清爽”上有什么可用支点，其他茶饮也可替换。
- 传播势能：4。挑战、快闪和抽奖是执行名词，尚无一个用户愿意参与或媒体愿意讲述的主动作。
- 逻辑通顺：4。目标含糊，无法推出动作优先级。
- 增长有效：2。没有明确要改变哪一个行为，也没有从行为到结果的路径。

不评维度：无。

证据边界：未提供 Brief，以下判断只基于方案文本；不推定新品口味、门店资源、价格或外卖能力。

当前最该加分：增长有效。增长目标不清，后面的创意、传播和优惠都没有共同服务对象。

## 更锋利的一版

先不要从“夏天很热”开始，也不要急着把券塞进每个平台。把问题定成一个要被改变的行为：例如，若客户确认新品面对的是午后经过门店却总选熟悉款的人，那么核心不是让人知道它清爽，而是让第一次点它变得有理由。整案可围绕 `今天这杯，给下午留一口空出来` 展开：门店试饮不是泛尝鲜，而是让用户在午后高温或工作间隙完成一次“替换原选择”的小测试；短视频只记录人们给下午腾出一点空间的具体时刻；快闪把同一动作做成可拍的“留一口空”装置；外卖承接则只服务已完成试饮或看过该动作的人。这里的券只是降低第一次替换的门槛，不是创意本身。若真正业务问题是复购或外卖转化，必须先换成对应的人群行为，再保留同一条从动作到结果的结构。

## 下一步怎么改

1. 先确认本轮唯一优先行为是尝鲜、复购、到店还是外卖转化，并删去不服务它的渠道动作。
2. 围绕一个具体夏日触发时刻重写试饮、内容和快闪，使每一项都重复同一个主动作。
```
