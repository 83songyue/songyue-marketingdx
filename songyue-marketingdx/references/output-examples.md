# Output Examples

These examples show the expected reasoning shape. They are not based on real customer proposals.

## Example 1: Strategy / Brand

User asks: `帮我看这份品牌定位方案，重点判断它的问题定义和品牌主张是否成立。`

Input summary: A home appliance brand wants to move from "durable and reliable" to "daily comfort partner", but the proposal only lists trends, competitors, and several broad proposition lines.

Expected first response shape:

```markdown
## 核心判断

这份方案的方向不一定错，但现在还不是一个成立的品牌定位。它把“日常舒适伙伴”当成结论，却没有说明为什么原来的“耐用可靠”不够了、目标人群在哪个生活场景里需要这种升级，以及品牌凭什么能占据这个角色。

## 为什么这样判断

方案类型：策略/品牌

适用维度：商业问题定义、人群与场景、战略主张、证据与可行性

不评维度：创意表达，本方案不评；渠道与行动设计，本方案不评。

证据边界：未提供 Brief，以下判断只基于方案文本。

看到了什么：方案有趋势和竞品，但缺少目标人群场景。

因此判断：新定位是一个愿望，不是一个从业务问题和品牌资产推出的选择。

## 更锋利的一版

把问题改成：这个品牌过去靠可靠赢得信任，但新一代家庭用户不只想买一个耐用品，而是想减少每天使用中的麻烦、打扰和不确定。

## 下一步怎么改

先补四件事：旧定位遇到什么增长瓶颈；目标人群在哪个具体场景里需要舒适；舒适到底是省心、安静、健康还是秩序；品牌有什么产品、服务或历史资产能支撑。
```

## Example 2: Communications / PR

User asks: `诊断方案：这是一份传播/公关发布方案，帮我判断它站不站得住。`

Input summary: A B2B software product plans a launch around "redefining team efficiency", with press release, founder interview, analyst briefing, and customer quote posters, but no news hook or proof.

Expected first response shape:

```markdown
## 核心判断

这份传播方案的问题不是动作少，而是没有公共理由。它有新闻稿、采访和媒体沟通，但还没有说明为什么外部媒体或行业用户应该在此刻关心“重新定义效率”。

## 为什么这样判断

方案类型：传播/公关

适用维度：商业问题定义、人群与场景、战略主张、渠道与行动设计、证据与可行性

不评维度：创意表达，本方案不评。当前材料没有提供足够创意表达，只能评价话题和传播机制。

证据边界：未提供 Brief，以下判断只基于方案文本。

看到了什么：方案列出了发布动作，但核心说法缺少事实证据。

因此判断：它更像一次产品公告流程，不像一个能被报道和复述的行业话题。

## 更锋利的一版

把“重新定义团队效率”改成一个可证明的矛盾：团队不是缺少工具，而是被过多工具切碎了协作。新品发布要证明它减少了哪一种具体摩擦。

## 下一步怎么改

补一个能被媒体引用的证据：行业观察、用户行为变化、典型客户前后对比或一个可公开验证的产品动作。再围绕这个证据设计发布顺序。
```
