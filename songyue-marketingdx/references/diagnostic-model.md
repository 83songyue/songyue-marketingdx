# Public Diagnostic Model

Use this reference for public L1.5 diagnosis only. Do not add private root-cause chains, hidden scoring rubrics, or real client mappings.

## Six Dimensions

1. `商业问题定义`: Whether the proposal names the real business problem, not only a communication task.
2. `人群与场景`: Whether the target audience, usage/decision scene, and tension are specific enough to guide choices.
3. `战略主张`: Whether the core proposition gives the brand a clear role, point of view, and priority.
4. `创意表达`: Whether the idea, copy, content, or symbol system makes the proposition sharper and easier to remember.
5. `渠道与行动设计`: Whether the touchpoints, sequence, participation mechanism, and conversion/action path support the goal.
6. `证据与可行性`: Whether claims are supported by Brief facts, observable plan evidence, resource assumptions, and operational feasibility.

## Type Applicability

| Proposal Type | Core Dimensions | Usually Mark `本方案不评` |
| --- | --- | --- |
| `整合营销` | 商业问题定义; 人群与场景; 战略主张; 创意表达; 渠道与行动设计; 证据与可行性 | None by default |
| `传播/公关` | 商业问题定义; 人群与场景; 战略主张; 渠道与行动设计; 证据与可行性 | 创意表达, unless the PR idea or topic expression is central |
| `策略/品牌` | 商业问题定义; 人群与场景; 战略主张; 证据与可行性 | 创意表达; 渠道与行动设计 |
| `创意/内容` | 人群与场景; 战略主张; 创意表达; 证据与可行性 | 商业问题定义; 渠道与行动设计, unless the submission includes them |

If a proposal contains enough substance in a normally non-core dimension, evaluate it briefly and explain why it is being included.

## Evidence Boundary

- Treat the Brief as context, not proof of execution quality.
- Treat the proposal as the main object of diagnosis.
- If the user gives no Brief, state `未提供 Brief，以下判断只基于方案文本`.
- Do not infer budget, team capacity, media resources, brand history, sales performance, or audience data unless explicitly provided.
- When a claim depends on missing evidence, label it as `待验证`.

## Long-Document Protocol

For long proposals:

1. Build a section map by heading, page, or natural block.
2. Extract one to three evidence bullets per relevant section.
3. Diagnose from the evidence list instead of from memory of isolated sentences.
4. If the document is too long for one turn, ask the user to provide the next segment or specify the target section.

## Diagnosis Depth

Stay at public L1.5:

- Identify type, evidence gaps, structural problems, weak assumptions, and sharper revision directions.
- Do not reveal private root-cause routes, expert correction libraries, PR risk rules, or internal calibration standards.
